# ADR-007 — API contract conventions

- Status: accepted
- Date: 2026-10-25
- Decision: D10 (routes) and §5.8 conventions; D10 confirmed on 2026-10-25

## Context

The legacy exposes PascalCase routes under `/api` (`/api/Providers`, `/api/Applications/...`), with the typo `/api/Enviroments`. Lists have two forms (`/X` and `/X/Paginated`) and responses `{totalCount, results}`. Enums are a mix of integers and strings. The frontend is the only client, so the contract can be fixed without external compatibility.

## Decision

- Base `/api`, lowercase plural kebab-case resources: `/api/providers`, `/api/environments`, `/api/provider-environments`, `/api/application-versions`, `/api/application-version-apis`, `/api/command-executions`.
- Separate auth BFF: `GET /auth/login`, `GET /auth/callback`, `POST /auth/logout`, `GET /api/session`. No token endpoint exposed to the SPA.
- JSON camelCase; UTC ISO 8601 dates; enums as strings.
- Lists: `page` (1-based), `pageSize` (max 200), `sort`, `q`; response `{items,total,page,pageSize}`. No separate `/Paginated`.
- RFC 7807 errors with a stable `code` and `traceId`; 400/401/403/404/409/422.
- `ETag`/`If-Match` on diagrams; `Idempotency-Key` on remote executions.
- OpenAPI 3.x generated by the backend and versioned; CI fails if the TypeScript client drifts.
- `Enviroments` has no alias in v1; the alias is added only for an external client (D10).

## Alternatives considered

- **Keep PascalCase and `/Enviroments`**: zero changes to the legacy frontend, but it passes on a typo and an inconsistent contract.
- **URL versioning `/api/v1`**: not necessary while the only client is the SPA; it is added if an external client appears.
- **`/Enviroments` alias**: rejected in v1; adding it later costs little, maintaining two routes from the start costs time.

## Consequences

- All frontend calls change; the legacy → target mapping is in `docs/api/route-inventory.md`.
- The single list replaces `/X/Paginated`; selects use a high `pageSize` or a dedicated endpoint if needed.
- The contract becomes a release artifact: OpenAPI and `schema.d.ts` are mandatory.
